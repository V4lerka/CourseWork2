## Использование🛠️
* Клонируйте репозиторий: `git clone git@github.com:V4lerka/CourseWork2.git`
* Установите зависимости из **pyproject.toml**: `poetry install`
* При необходимости обновите зависимости: `poetry update`

## Описание функционала:🪄
* Модуль **api.py** содержит классы для работы с API сервисов [OpenSky](https://opensky-network.org/) и 
[Nominatim](https://nominatim.openstreetmap.org/ui/search.html).
* Модуль **aeroplanes.py** содержит класс Aeroplane для работы с объектами класса Самолет.
* Модуль **utils.py** содержит классы для работы с файлами (поддерживает функциии сохранения в файл, добавления в файл, 
поиска информации в файле по критерию и очистки содержимого файла).

## Запуск🚀
- Запускаем команду в терминале `python main.py`, при этом активируется консольный интерфейс взаимодействия с 
пользователем, данные о самолетах также могут быть сохранены в JSON-файл при выборе этой опции.
